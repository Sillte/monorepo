# uv workspace sample

This repository is a small Python monorepo managed as one uv workspace. It contains an application and a reusable package; `hello-app` depends on the local `greetings` workspace member.

## Structure

```text
apps/
  hello-app/       # Runnable application
packages/
  greetings/       # Reusable library
pyproject.toml     # Workspace root
uv.lock            # Shared lockfile (generated by uv)
```

## Try it

From the repository root:

```powershell
uv sync
uv run --package greetings greetings --name Alice
uv run --package hello-app hello-app greet --name Alice
```

Expected output:

```text
Hello, Alice!
```

Add new projects under `apps/` or `packages/`; the root workspace globs discover their `pyproject.toml` files. Declare an internal dependency with a regular project dependency and a `[tool.uv.sources]` entry using `workspace = true`.

Both workspace packages install Click and expose a console script: `greetings` for the library package and `hello-app` for the application. Run `uv run --package <package> <command> --help` to inspect each CLI's options.

## Agent Skills

This repository includes one CLI-backed Skill inside each workspace package, using the package-local `.github/skills/<skill-name>/SKILL.md` layout:

- [`greetings-cli`](packages/greetings/.github/skills/greetings-cli/SKILL.md) runs the `greetings` CLI from the `greetings` package.
- [`hello-app-cli`](apps/hello-app/.github/skills/hello-app-cli/SKILL.md) runs the `hello-app` CLI from the `hello-app` package.

Both Skills use `uv tool run --from <package-path>` so they exercise the selected member's installed console entry point. Run these commands from the monorepo root.
